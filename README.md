# Штаб винахідника v2 (ітерації 1-2)

## Що нового порівняно з v1

- Кілька файлів замість одного HTML: кожен модуль окремо, нове простіше додавати.
- Ноти замість XP: нараховуються одразу, зі звуком і анімацією.
- Вкладка "День": тижнева ціль, рутини (ранок / після школи / вечір), домашнє завдання, разові завдання.
- Вкладка "Ноти": обмін на бонусний екранний час, скарбничка, історія.
- Міні-місія (3 задачі) і повна місія (8 задач).
- Панель для батьків за PIN-кодом: рутини, разові завдання, екранний час, скарбничка, ручний бонус, рівні, резервна копія, Google Таблиця.
- Прогрес v1 переноситься автоматично при першому відкритті в тому самому браузері.

## Як опублікувати (один раз, з комп'ютера)

1. Розпакуйте архів (правою кнопкою -> "Видобути все").
2. github.com -> Sign up -> зареєструйтесь і підтвердьте пошту.
3. "+" вгорі праворуч -> New repository. Назва, наприклад, studio. Public. Позначте "Add a README file". Create repository.
4. Add file -> Upload files -> перетягніть усе з розпакованої папки (index.html, css, js, tests, Code.gs, README.md). Commit changes.
5. Settings -> Pages -> Branch: main, папка / (root) -> Save. Через 1-3 хв оновіть сторінку: з'явиться адреса сайту.
6. На телефоні дитини відкрийте адресу в Chrome -> меню (три крапки) -> "Додати на головний екран".

Оновлення пізніше: Add file -> Upload files -> перетягніть нові файли поверх старих -> Commit changes.

## Перший запуск

1. Вкладка "Батькам" -> задайте PIN (4-8 цифр). Не показуйте його дитині.
2. Перевірте рутини, екранний час і дні з домашкою. За замовчуванням: базовий час 60 хв, стеля 120 хв, 10 хв бонусу = 15 нот, бонус лише після домашки в пн-пт.
3. Придумайте разом назву застосунку ("Загальне і дані" -> назва).

## Екранний час

Застосунок не керує телефоном. Коли дитина обмінює ноти, ви вводите PIN, а час додаєте в Google Family Link (Бонусний час) або дозволяєте вручну.

## Якщо забули PIN

Відкрийте адресу сайту з `#reset-pin` у кінці, наприклад `https://<логін>.github.io/<репо>/#reset-pin`. Прогрес не зміниться.

## Резервна копія

Прогрес живе в браузері планшета. Раз на тиждень: "Батькам" -> "Загальне і дані" -> "Зберегти копію у файл".
